# Security policy

This is a personal homelab repository, not a product with supported versions. Everything on `main` is what's deployed.

## Reporting a vulnerability

If you find a security problem in this repo's configuration or workflows, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/jakerobb/homelab/security/advisories/new) rather than
opening a public issue. Expect a reply when I get to it, not on a schedule.

No secrets live in this repo in plaintext (they're SOPS-encrypted or kept in 1Password). If you spot one that isn't,
that's worth reporting.
